### What I worked on
- Installed Unity 6 LTS and set up a project with the URP template
- Installed Visual Studio and configured it as the Unity editor
- Installed GitHub Desktop, created a repository for the project and connected it to GitHub

### What I learned
- Git doesn't link to Unity directly. It just tracks the project folder.
- GitHub Desktop is a visual front end for Git and bundles its own copy of Git.
- Installing GitHub Desktop does not make `git` available in the terminal.

### What got me stuck (and how I fixed it)
- `git init` in PowerShell gave a "term 'git' is not recognized" error. The cause was that I had installed GitHub Desktop rather than standalone Git, so the terminal had no Git to find. I'm using GitHub Desktop going forward and will come back to the command line later.
